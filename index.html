📐 Mathematical Parameter Calibration (Driven by results.json)
Rather than using static heuristics, DeepCVD calculates color recovery transfer matrices dynamically from the empirical test results recorded in results.json for the active deficiency condition.
1. Chromatic Recovery Weight
W_chroma = [0.40 + 0.65 · (1 - ΔE_m / ΔE_base) · √(PSNR_m / PSNR_base)] · M_contrast
Scales orthogonal chromatic remapping proportionally to CIEDE2000 error reduction and signal-to-noise ratio.
2. Structural Edge Factor
W_edge = [0.20 + 0.45 · (Q_m - Q_base) / (1 - Q_base)] · M_edge
Where Q = MS-SSIM · (1 - LPIPS). Restores boundary contrast along confusion lines (e.g. Ishihara dots) without ringing.
3. Luminance Compensation
W_lum = 0.08 + 0.12 · min(1.0, ΔPSNR / 8.0 dB)
Compensates for lost cone spectral absorption (e.g., L-cone loss in Protanopia) by boosting red band luminance.
4. Ablation Architecture Modulation
M_contrast = (PSNR_var / PSNR_base_abl) · (LPIPS_base_abl / LPIPS_var)
Modulates Restormer weights dynamically using the selected architecture row from results.json ablation study.
